# Sélecta

Sélecta affiche une barre d'actions quand vous sélectionnez du texte sur votre Mac : copier, chercher,
et les actions des extensions que vous installez, comme la traduction.

- Téléchargement : la dernière version est dans les [Releases](https://github.com/rapha-blt/selecta/releases/latest).
- Configuration requise : macOS 14 ou plus récent.
- Mises à jour : une fois installé, Sélecta cherche lui-même les nouvelles versions et vous propose de
  les installer. Il lit le flux [appcast.xml](https://rapha-blt.github.io/selecta/appcast.xml), publié
  par GitHub Pages depuis ce dépôt, et vérifie la signature de chaque version avant de l'installer.

Ce dépôt ne contient que les versions publiées et leur flux de mises à jour.
