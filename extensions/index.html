Guide des extensions

Créez vos propres boutons.

Une extension ajoute des boutons à la barre de Sélecta. Elle peut ouvrir une adresse, taper un raccourci clavier, lancer un Raccourci, ou exécuter un script JavaScript, TypeScript, AppleScript ou Shell qui reçoit le texte sélectionné. Ce guide part d'un exemple de quatre lignes et va jusqu'au détail du format.

  • Un seul fichier suffit
  • Sans code, ou avec un script
  • Rien ne s'exécute sans votre clic

Votre première extension

Quatre lignes suffisent. Les lignes commentées du début décrivent l'extension ; le reste est le code lancé quand vous cliquez sur le bouton.

  1. Enregistrez ces lignes dans un fichier bonjour.js.
  2. Ouvrez les réglages de Sélecta, onglet Extensions, et faites-y glisser le fichier.
  3. Sélectionnez un mot n'importe où : un bouton en forme de main apparaît dans la barre. Cliquez dessus : la barre affiche « Bonjour, … ! ».

Encore plus rapide : sélectionnez le code ci-dessus avec Sélecta. La barre reconnaît une extension et propose « Installer l'extension » en premier bouton.

Snippet, paquet, archive

Une extension tient dans un seul fichier, le snippet, ou dans un dossier, le paquet, qu'on peut compresser pour l'envoyer.

Un fichier : le snippet

  • Extensions de fichier acceptées : .js, .ts, .yaml, .yml et .txt (par convention .selecta.txt).
  • La ligne #selecta est dans les trois premières lignes, après un éventuel shebang (#!/bin/zsh) ou des lignes vides.
  • Chaque ligne d'en-tête commence par le même préfixe de commentaire : //, # ou --.
  • L'en-tête est du YAML, avec les mêmes clés qu'un Config.yaml. Il s'arrête à la première ligne sans ce préfixe ; le reste du fichier est le code de l'action.
  • Le langage vient de l'extension du fichier (.js, .ts) ou de la clé language : javascript, typescript, applescript ou shell. Sans l'un ni l'autre, c'est du JavaScript.
  • Un snippet décrit une seule action et ne peut pas utiliser d'autre fichier, comme une icône ou un script à part : pour cela, il faut un paquet.

Les numéros de ligne des erreurs correspondent au fichier, en-tête compris. Un script Shell garde son shebang.

Un dossier : le paquet .selectaext

Un dossier dont le nom finit par .selectaext. Quand Sélecta est installée, le Finder l'affiche comme un seul fichier. Il contient :

  • Config.yaml, Config.yml ou Config.json ;
  • les fichiers que la config cite : scripts (javascriptFile, appleScriptFile, shellScriptFile) et icônes ;
  • ce que vous voulez d'autre : un README, une licence.

Les chemins sont relatifs au dossier du paquet et ne peuvent pas en sortir : pas de / au début, pas de ~, pas de ... Les liens symboliques sont refusés.

Une archive : .selectaextz

Le paquet compressé en zip, pratique à envoyer par e-mail ou à proposer au téléchargement. L'archive contient les fichiers du paquet, ou un seul dossier qui les contient. Pour la créer dans le Terminal :

Du texte sélectionné

Le code d'un snippet, ou une config YAML ou JSON, dans un e-mail, une page web ou une note : sélectionnez-le, et la barre propose « Installer l'extension ». Le texte doit faire moins de 64 Ko, et contenir #selecta dans ses trois premières lignes, ou être un YAML ou un objet JSON avec name et une action.

Installer et mettre à jour

  • Double-cliquez sur un .selectaext ou un .selectaextz.
  • Faites glisser un fichier sur l'onglet Extensions des réglages.
  • Cliquez sur le bouton + de l'onglet Extensions.
  • Ou sélectionnez le code de l'extension, puis cliquez sur « Installer l'extension » dans la barre.

Sélecta garde sa propre copie de l'extension : vous pouvez ensuite supprimer le fichier d'origine. Une extension qui n'utilise ni Internet, ni AppleScript, ni Shell s'installe directement ; sinon, Sélecta vous montre d'abord ce qu'elle pourra faire (voir Sécurité).

Pour mettre une extension à jour, réinstallez-la avec le même identifier : elle est remplacée après confirmation, et ses réglages sont gardés. Avec la synchro iCloud (Réglages › Général), vos extensions passent aussi sur vos autres Mac.

Pour relire les fichiers d'une extension installée : onglet Extensions › « Source… ».

Actions sans code

Une seule clé dit ce que fait le bouton. Quatre d'entre elles ne demandent aucun code.

url : ouvrir une adresse

*** est remplacé par la sélection, sans les espaces et retours à la ligne du début et de la fin, et encodée pour une adresse (&, =, +, ? et # compris). Sans ***, l'adresse s'ouvre telle quelle. Tout schéma marche : https:, mailto:, x-apple.systempreferences:, celui d'une app…

keyCombo : taper un raccourci clavier

Des modificateurs dans n'importe quel ordre, puis une touche, séparés par des espaces ou des + :

  • modificateurs : command (cmd, ⌘), shift (⇧), option (opt, alt, ⌥), control (ctrl, ⌃) ;
  • touche : un caractère (b, é, 1, /), ou return (enter), tab, space, escape (esc), delete (backspace).

La touche suit la disposition du clavier : command z tape bien ⌘Z sur un clavier AZERTY.

service : appeler un service macOS

Le nom que l'app déclare, en anglais, même quand le menu Services l'affiche en français : « Make Sticky » et non « Créer une nouvelle note ». Il se trouve dans l'Info.plist de l'app (clic droit sur l'app › Afficher le contenu du paquet › Contents), sous NSServices › NSMenuItem › default. Si le service renvoie du texte, c'est le résultat de l'action.

shortcut : lancer un Raccourci

Le nom exact du Raccourci, majuscules et accents compris. La sélection est son entrée ; ce qu'il renvoie avec « Arrêter et renvoyer », ou sa dernière action, est le résultat. Au premier lancement après l'ouverture de session, macOS met quelques secondes à démarrer Raccourcis et la barre se ferme : un résultat à afficher est alors perdu. Les clics suivants sont rapides.

Plusieurs boutons

La clé actions liste plusieurs actions, chacune avec son title. Les clés données à la racine (requirements, regex, apps, excludedApps, before, after, stayVisible et timeout) valent pour toutes les actions qui ne les redonnent pas.

Une extension a soit actions, soit une action décrite directement à la racine, comme dans les exemples précédents, pas les deux. Dans l'onglet Actions des réglages, chaque bouton se range, se cache ou se met dans un dossier comme les actions de Sélecta.

Quand le bouton apparaît

Le bouton n'apparaît que si toutes ses conditions sont remplies.

requirements

ConditionVraie quand
textla sélection n'est pas vide, ni faite que d'espaces (par défaut)
copyla sélection peut être copiée
pastela sélection est dans un champ modifiable
urlla sélection contient une adresse web
emailelle contient une adresse e-mail
pathelle contient un chemin de fichier

Un ! devant une condition la renverse ; en YAML, mettez-la alors entre guillemets. Une seule condition peut s'écrire sans crochets : requirements: paste.

regex

La sélection doit contenir une correspondance (syntaxe ICU, celle de NSRegularExpression). Le texte reconnu remplace alors la sélection pour l'action : c'est lui que reçoivent ***, les services, les Raccourcis et les scripts AppleScript et Shell. En JavaScript, il est dans sel.input.matchedText, le texte entier restant dans sel.input.text. Mettez la regex entre apostrophes pour que les \ restent tels quels ; (?i) au début ignore la casse.

apps et excludedApps

Les seules apps où le bouton apparaît, ou celles où il n'apparaît pas, par leur identifiant : com.apple.TextEdit, com.apple.Safari, com.microsoft.VSCode… Pour trouver celui d'une app :

Que faire du résultat

after dit ce que devient le résultat de l'action : ce que renvoie le script, le service ou le Raccourci. Sans after, il est ignoré, et un résultat vide ne fait rien.

ValeurEffet
copyLe résultat va dans le presse-papiers.
paste-resultLe résultat remplace la sélection. Hors d'un champ modifiable, il est copié et la barre le dit.
show-resultLe résultat s'affiche dans la barre.
show-statusUne coche ou une croix s'affiche, sans le résultat.
preview-resultLe résultat devient un bouton de la barre : un clic dessus le colle si le champ est modifiable, le copie sinon.

before: copy copie la sélection (⌘C) avant l'action, pour une app qui ne donne pas sa sélection autrement. Si rien n'est copié en une demi-seconde, l'action n'est pas lancée.

Une action url ou keyCombo ferme la barre avant de s'exécuter, sauf avec stayVisible: true ou un after qui s'affiche dans la barre. Les autres gardent la barre ouverte, avec un indicateur d'attente, jusqu'à leur fin. timeout borne leur durée : 10 secondes par défaut, 60 au plus. En cas d'erreur, la barre affiche une croix rouge et le message.

Icônes

FormeExempleRendu
symbol:<nom>symbol:globeUn symbole SF ; les noms se trouvent dans l'app SF Symbols d'Apple.
text:<texte>text:DEQuelques lettres, 6 caractères au plus.
un fichier du paqueticone.pngUne image png, pdf, svg, jpg, jpeg, heic ou tiff.

Une valeur courte sans préfixe, comme DE, vaut text:DE. Une image s'affiche telle quelle, sans s'adapter au mode sombre : choisissez-la lisible sur fond clair comme sur fond sombre. Préférez un PDF ou un SVG, ou un PNG d'au moins 32 × 32 pixels. Sans icône, le bouton affiche son titre.

JavaScript et TypeScript

Le code est le corps d'une fonction async : await marche directement, et return donne le résultat de l'action, que after utilise.

  • Un texte renvoyé est utilisé tel quel ; un objet ou un tableau devient du JSON, un nombre ou un booléen son texte ; undefined et null veulent dire « pas de résultat ».
  • Une exception non rattrapée, ou une promesse rejetée, fait échouer l'action : la barre affiche une croix et le message, avec sa ligne.
  • Chaque clic part d'un environnement neuf : rien ne reste d'un clic à l'autre.
  • Le moteur est JavaScriptCore, celui de Safari : du JavaScript moderne, sans DOM ni window, sans import ni require.

YAML sur une ligne : un code qui contient « : » suivi d'une espace, ou qui commence par {, [, `, *, &, !, % ou @, est mal lu. Mettez-le dans un bloc |, comme ci-dessus.

Les fonctions de sel

Celles qui agissent sur le système renvoient une promesse : mettez await devant si la suite en dépend.

FonctionDescription
sel.copyText(texte)Met le texte dans le presse-papiers.
sel.pasteText(texte)Remplace la sélection par le texte ; hors d'un champ modifiable, le copie.
sel.showText(texte)Affiche le texte dans la barre à la fin du script.
sel.showSuccess()Affiche une coche à la fin du script.
sel.showFailure(message?)Fait échouer l'action : une croix, et le message s'il y en a un.
sel.openUrl(adresse)Ouvre l'adresse, qui doit avoir un schéma (https:…).
sel.pressKey(combinaison)Tape une combinaison, comme keyCombo ("command shift k").
sel.performService(nom, texte?)Appelle un service ; renvoie son texte, ou null.
sel.runShortcut(nom, entrée?)Lance un Raccourci ; renvoie sa sortie, ou null.
sel.runAppleScript(code, texte?)Lance un AppleScript (entitlement applescript) ; renvoie sa sortie, ou null.
sel.runShellScript(code, texte?)Lance un script Shell, /bin/zsh sauf shebang (entitlement shell) ; renvoie sa sortie, ou null.

Sans texte, les quatre dernières reçoivent sel.input.matchedText. showText, showSuccess et showFailure notent ce que la barre affichera à la fin du script : le dernier appel l'emporte, et showFailure passe avant tout, rien n'est alors collé ni copié. showText et showSuccess ne s'affichent que si after n'affiche rien lui-même.

fetch : aller sur Internet

Avec l'entitlement network seulement, et pour des adresses http: ou https:.

  • Options : method (GET par défaut), headers (un objet), body (un texte : passez par JSON.stringify pour un objet).
  • Réponse : url, status, statusText, ok (code de 200 à 299), headers (noms en minuscules), text() et json().
  • Une réponse d'erreur (404, 500) n'est pas une exception : testez ok ou status. fetch ne rejette que si la requête n'aboutit pas.
  • Pas de cookies ni de cache ; la réponse est limitée à 10 Mo.

Autres outils

  • util.base64.encode(texte), util.base64.decode(base64) ; util.hash.sha256(texte), sha1 et md5, en hexadécimal minuscule.
  • console.log(…), et info, warn, error, debug : écrit dans les journaux de Sélecta quand « Journaux des extensions » est activé (voir Dépannage).
  • setTimeout et clearTimeout : les minuteurs encore en attente à la fin du script sont annulés.

TypeScript

Avec la clé typescript, ou un fichier .ts, Sélecta retire les types avant de lancer le code, sans les vérifier. Seule la syntaxe qui disparaît sans rien changer au code est acceptée, comme avec l'option --erasableSyntaxOnly de TypeScript :

  • acceptés : annotations de type, interface, type, as, satisfies, ! non nul, génériques, declare, public / private / protected / readonly sur les champs, implements ;
  • refusés : enum, namespace, propriétés de paramètres (constructor(private x: number)), décorateurs, import x =.

AppleScript

Le script reçoit selectaText, le texte reconnu (la sélection, ou ce que reconnaît la regex), et selectaOptions, un enregistrement des options : formel of selectaOptions. Ce que le script renvoie, avec return ou par sa dernière instruction, est le résultat de l'action.

Automatisation : la première fois qu'un script pilote une app (Notes, Mail, Finder…), macOS demande si Sélecta peut la contrôler. Cette demande ferme la barre, et ce premier clic échoue souvent. Répondez « Autoriser », puis cliquez à nouveau sur le bouton. Si vous avez refusé, réautorisez Sélecta dans Réglages Système › Confidentialité et sécurité › Automatisation.

Shell

Le script reçoit SELECTA_TEXT, le texte reconnu, et SELECTA_OPTION_<ID> pour chaque option : l'identifiant en majuscules, - remplacé par _, et 1 ou 0 pour une option boolean. Ce qu'il écrit sur la sortie standard, sans les retours à la ligne de la fin, est le résultat. Un code de sortie autre que 0 fait échouer l'action, avec ce que le script a écrit sur la sortie d'erreur.

  • Interpréteur : la clé interpreter (un chemin absolu, comme /usr/bin/python3), sinon le shebang du script, sinon /bin/zsh.
  • Environnement : réduit à PATH (avec /opt/homebrew/bin et /usr/local/bin), HOME, USER, LOGNAME, SHELL, TMPDIR et LANG. Votre ~/.zshrc n'est pas lu : écrivez le chemin complet d'un outil installé ailleurs.
  • Dossier courant : celui de l'extension, pour lancer un autre fichier du paquet (./outil.py).
  • Rien n'arrive sur l'entrée standard : passez par SELECTA_TEXT, toujours entre guillemets ("$SELECTA_TEXT"), car le texte peut contenir des espaces, des * ou des ;.

Options et instances

Les options sont des réglages que l'utilisateur remplit dans l'onglet Extensions. Le script les lit dans sel.options (JavaScript), selectaOptions (AppleScript) ou SELECTA_OPTION_<ID> (Shell).

TypeRéglageValeur reçuePar défaut
stringchamp de textetextedefaultValue, sinon vide
booleaninterrupteurtrue / falsedefaultValue, sinon false
multiplemenul'un des valuesdefaultValue, sinon le premier
secretchamp masquétextevide

Chaque option a un identifier (une lettre, puis des lettres, chiffres, _ ou -), et peut avoir un label, une description affichée dessous et une defaultValue, sauf un secret. values est obligatoire pour multiple.

Un secret, comme une clé d'API, est rangé dans le Trousseau de macOS, jamais dans les préférences de Sélecta. Il n'est jamais réaffiché, et le script ne le reçoit qu'au moment du clic. Ne l'écrivez pas dans les journaux.

Une instance est une copie de l'extension avec son nom, son icône et ses valeurs d'options. « Dupliquer », dans l'onglet Extensions, en crée une : par exemple « DeepL » vers le français et « DeepL allemand » vers l'allemand, chacune avec son bouton.

Sécurité

Une extension ne s'exécute que quand vous cliquez sur son bouton : aucun code ne tourne à l'installation, ni quand la barre apparaît. Pour aller au-delà de la sélection, elle doit le déclarer dans entitlements :

EntitlementPermetCe que Sélecta vous dit avant l'installation
networkfetch en JavaScriptAccéder à Internet, y compris pour envoyer le texte sélectionné à un site.
applescriptles actions AppleScript, sel.runAppleScriptContrôler d'autres applications, lire leurs données et agir à votre place.
shellles actions Shell, sel.runShellScriptExécuter des commandes avec vos droits, donc lire, modifier ou supprimer vos fichiers.

applescript et shell sont ajoutés d'office à une extension qui a une action de ce langage ; network doit être déclaré. Une extension sans aucun de ces droits s'installe directement. Sinon, Sélecta affiche cette liste et attend votre accord ; le bouton par défaut est « Annuler ». Une fonction appelée sans son entitlement échoue avec un message qui le nomme.

Si les fichiers d'une telle extension changent après l'installation, Sélecta la désactive et vous redemande votre accord. Avec iCloud, elle attend aussi votre accord sur chaque Mac. Ne demandez que les droits nécessaires, et dites pourquoi dans description.

Dépannage

L'installation est refusée
Le message donne la clé fautive et sa ligne, par exemple actions[1].requirements (ligne 9) : « urll » n'est pas un requirement connu. actions[1] est la deuxième action : on compte à partir de 0.
Le bouton n'apparaît pas
Vérifiez dans l'onglet Actions que l'action est cochée, puis requirements (paste demande un champ modifiable), regex, apps et excludedApps. Les exclusions de Sélecta cachent aussi la barre entière dans certaines apps.
« … est introuvable. »
Pour un service, ce n'est pas le nom anglais déclaré par l'app. Pour un Raccourci, le nom ne correspond pas exactement, majuscules et accents compris.
« … a mis trop de temps et a été arrêté. »
Augmentez timeout, jusqu'à 60. Pour un AppleScript, c'est aussi ce qui arrive au premier clic qui déclenche la demande d'Automatisation.
« Cette extension n'a pas le droit… »
Ajoutez l'entitlement nommé dans le message à entitlements, puis réinstallez l'extension.
Le résultat n'est ni collé ni affiché
Il faut un after, et un résultat vide ne fait rien.
Lire les messages d'erreur et les console.log
Le message complet est dans les journaux de Sélecta. Ouvrez l'app Console (ou « Ouvrir Console » dans l'onglet Extensions), cliquez sur « Démarrer », tapez subsystem:app.selecta dans la recherche, puis cliquez sur le bouton de l'extension. Pour voir aussi les console.log et la sortie d'erreur des scripts, activez « Journaux des extensions » dans l'onglet Extensions et ajoutez category:Extension à la recherche ; désactivez-le ensuite.
